# fri-hojd-
Fri höjd – se låga broar och vägar med för låg bärighetsklass innan du kör. Ange ditt ekipages höjd, vikt och axeltryck, så visar appen vad du får plats under och vilka vägar (BK1–BK4) du får köra på. Karta, lista och körläge med röstvarning, baserat på Trafikverkets öppna vägdata. En app från Fabler &amp; Fakta Studio.
